# El Mexicano

A Next.js (App Router) + Tailwind CSS marketing site for El Mexicano, a Cali-Mex
restaurant brand in Egypt. Structure and flow modeled after
[tortillaarabia.com](https://tortillaarabia.com/): sticky header with top bar,
hero, brand story, menu grid, featured bundle, limited-time offers, delivery
platform links, locations, and footer.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Structure

- `src/app/` — root layout and homepage
- `src/components/` — page sections (Header, Hero, Story, Menu, Bundle, Offers, Delivery, Locations, Footer)
- `src/data/menu.ts` — menu items, limited-time offers, delivery platforms

## Build

```bash
npm run build
npm start
```
